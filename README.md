# Online Banking Database Management System

## Project Overview

This project is a SQL-based Online Banking Database Management System developed to simulate real-world banking operations and transaction workflows. The system is designed to manage customer accounts, banking transactions, loan records, and fund transfers using structured relational database concepts.

The project focuses on building a secure and organized banking database while applying SQL concepts such as table relationships, joins, stored procedures, triggers, and transaction management.

---

## Features

- Customer account management
- Savings and current account handling
- Fund transfer and transaction tracking
- Loan management system
- Transaction history records
- Banking analytics and reporting
- SQL triggers and stored procedures
- Relational database design

---

## Technologies Used

- SQL
- MySQL
- Relational Database Management System (RDBMS)

---

## Modules Included

### Customer Management
Stores customer details including account information, contact records, and banking profiles.

### Account Management
Handles account creation, balance tracking, account status management, and banking operations.

### Transaction Management
Manages deposits, withdrawals, and fund transfers while maintaining transaction history records.

### Loan Management
Stores loan information including loan type, amount, interest rate, and approval status.
